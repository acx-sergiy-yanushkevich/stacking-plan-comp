Text on leased fills is legible (specified #f6f2ff on the night leased fill is about 8.5:1). The plan's own shapes are not: leased and "no deal" fills are translucent and sit in the same purple as the card, so the stack reads as teal holes in the aurora. The wordmark is background-clip text with a transparent fill.
U5 Mobile & print visual quality: 3/3: At 390 px the building view becomes the phone stack, every tenant name is complete, and nothing in the name row overflows. The landscape Letter PDF is a separate white report (cover, rent roll, rollover and worklist), and on-screen print text matches the live KPIs (80.2% occupied, not a second rounding).
