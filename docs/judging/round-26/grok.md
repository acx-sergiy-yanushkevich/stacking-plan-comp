BUGS (with file:line):
- At `?view=map&ring=5` the half-mile pill and the building name occupy the same pixels, and the building name covers the count. Overlap is 21 px at 390×844, 11 px at 768 and 14 px at 1024. The walk label is anchored on the half-mile rim and the building label on the center (`src/components/map/MapView.tsx:314`), and the building marker is the later one at z-index 3 (`src/components/map/map.css:197`). - Bluebonnet live mode lists bus stops named “1”, “2”, “3” and “4” (`src/data/sources/OverpassSource.ts:172`). Those are the `name` tags in `src/data/snapshots/osm-P007.json` (for example the node at line 321). - A pin’s name is `data-label`, shown only while hovered (`src/components/map/map.css:208`). `.sp-pin.is-lit::after` (`src/components/map/map.css:209`) does not set opacity, so lighting a pin from the key, a row or a tap leaves the name hidden.
- Stop sorting uses `a.distanceMi - b.distanceMi || (a.type === 'Rail' ? -1 : 1)` (`src/data/sources/OverpassSource.ts:183`). Equal distances of the same kind never compare as equal, so the ordering is not a valid sort.
